# Add the bot

You need **Manage Server** to invite Shiva Toolbox and to change its settings.

<InviteButton />

The invite asks Discord for:

- View Channels
- Send Messages
- Embed Links
- Read Message History
- Add Reactions
- Manage Roles

Put the bot's role above every role it should assign. It cannot assign @everyone or a role managed by an integration.

## Commands for everyone

`/ping` checks the bot latency. `/status` lists what Shiva Toolbox can do on this server. Anyone can use them.

Every other command needs **Manage Server** and only works inside a server.
