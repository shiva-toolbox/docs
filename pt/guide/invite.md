# Adicionar o bot

É preciso ter **Gerenciar servidor** para convidar o Shiva Toolbox e para mudar as configurações.

<InviteButton />

O convite pede ao Discord:

- Ver canais
- Enviar mensagens
- Inserir links
- Ler histórico de mensagens
- Adicionar reações
- Gerenciar cargos

Coloque o cargo do bot acima de todo cargo que ele deve atribuir. Ele não atribui @everyone nem cargo gerenciado por uma integração.
