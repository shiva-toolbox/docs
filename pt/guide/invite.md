# Adicionar o bot

É preciso ter **Gerenciar servidor** para convidar o Shiva Toolbox e para mudar as configurações.

<InviteButton />

O convite pede ao Discord:

- Ver canais
- Enviar mensagens
- Inserir links
- Ler histórico de mensagens
- Adicionar reações
- Gerenciar cargos

Coloque o cargo do bot acima de todo cargo que ele deve atribuir. Ele não atribui @everyone nem cargo gerenciado por uma integração.

## Comandos para todo mundo

`/ping` mostra a latência do bot. `/status` lista o que o Shiva Toolbox faz neste servidor. Qualquer pessoa pode usar os dois.

Os outros comandos exigem **Gerenciar servidor** e só funcionam dentro de um servidor.
