# Shiva Docs

[English](#english) · [Português](#português)

## English

Public documentation for the [Shiva Toolbox](https://github.com/shiva-toolbox/shiva-toolbox) Discord bot. This repository does not import the bot.

### Local setup

```bash
pnpm install
cp .env.example .env
pnpm test
pnpm typecheck
```

`DISCORD_CLIENT_ID` is the public Discord application id. It is used later to build the invite button. Leave it empty for now.

## Português

Documentação pública do bot [Shiva Toolbox](https://github.com/shiva-toolbox/shiva-toolbox). Este repositório não importa o bot.

### Setup local

```bash
pnpm install
cp .env.example .env
pnpm test
pnpm typecheck
```

`DISCORD_CLIENT_ID` é o id público da aplicação no Discord. Ele entra depois, no botão de convite. Pode ficar vazio por enquanto.
